# 闪录（RFNOTER）使用教程

有两种用法，界面完全一样：**桌面端**（双击桌面上的「闪录」）和**网页端**（`npm start` 后浏览器访问）。下面凡是两者不同的地方都会标出来。

## 快速记录

底部固定栏就是「快速添加笔记」：

1. **日期**：自动填今天，不需要手动改。
2. **时间**：默认是从上一条笔记的结束时间开始，往后 40 分钟；第一次打开时会向上取整到 5 分钟。
3. **标题**：必填，一句话写清这条笔记是什么。
4. **标签**：可选，最多 20 个单位（一个汉字算 2 个，所以中文最多 10 个字），超出部分会自动截断。
5. 按回车或点「+」提交。

提交后，下一条笔记的起始时间会自动接上你刚才填的结束时间，连续记录时不用重复调时间。

**更快一点：**

- **常用条目**：输入框上方那一排是从你的历史里自动算出来的高频标题（记得最多的排在最前）。**点一下填入标题，双击直接记录一条**——像「CS」「B站」这种天天写的就不用再打字了。
- **补记空档**：右上角会显示「上一条 22:30 结束 · 空档 40分钟」。如果中间忘了记，点「补记空档」，起止时间会自动铺满这段空白，你只要写标题。
- **时间微调**：结束时间右边的 `−` / `+` 每次挪 5 分钟，「现在」把结束时间设成此刻；两个时间框都支持 `Alt + ↑/↓`。跨天会自动绕圈（23:58 + 5 分钟 = 00:03）。

## 导出与备份

点顶部的「导出」，会让你选格式：

| 格式 | 用途 |
| --- | --- |
| **JSON 完整备份** | 无损，可以再导入回来。定期导一份最稳 |
| **Markdown** | 按日期分节，给人读、发给别人看 |
| **CSV** | 给 Excel 或脚本用（自带 BOM，Excel 打开不乱码） |

导入只认 JSON 格式的备份文件，可以选择「合并」或「替换」。
日志和数据文件的说明见仓库里的《数据格式说明》。

> 💡 **桌面端**：在系统任何地方按 `Ctrl + Shift + Space`，窗口会立刻弹出并把光标放进输入框，打完回车就入库——这是最快的一条路径。

## 笔记列表

- 按日期分组，**今天**的分组默认展开，其他日期默认折叠；点日期标题可以展开/折叠。
- 卡片左侧的色条表示颜色标记。
- **双击卡片**，或者点卡片上的「修改详情」，可以编辑标题、时间、标签、颜色和详细信息。
- 点卡片右下角的箭头可以展开查看「详细信息」。
- **右键卡片**（手机上长按）会弹出菜单：编辑 / 复制 / 颜色标记 / 删除。
  - 「复制」会以当前时间向上取整到 5 分钟为起点，复制出一个等长的新笔记。
  - 「颜色标记」里的「默认」表示不使用颜色。
- 删除有二次确认，且不可撤销，请谨慎操作。

## 选择笔记与 AI 总结

1. 点右上角 **选择笔记** 进入选择模式。
2. 点单条笔记来勾选/取消；点日期标题可以整组全选或整组取消。
3. 最多可以选 100 条。
4. 选好后点 **确认，开始AI总结**，或者点右下角浮动的 **AI 总结** 按钮。
5. 在配置弹窗里选择：
   - **总结风格**：简洁摘要 / 详细报告 / 记忆回溯。
   - **输出格式**：纯文本 / Markdown / HTML。HTML 会被安全过滤后渲染，只保留白名单标签。
   - **自定义提示词**：可选，例如"请重点关注时间安排和任务优先级"。
   - **高级设置**：填 DeepSeek API 密钥（只保存在本机浏览器）、选择模型、调整温度。密钥输入框失焦后会自动拉取一次可用模型列表。
6. 生成完成后可以 **复制到剪贴板**、**保存为新笔记**、**重新生成**（沿用当前配置再算一次）或 **调整配置**（回到配置弹窗重选）。

> 密钥只存在当前页面的内存里，刷新后需要重新输入，不会上传到任何服务器。

## 数据保存在哪

| 形态 | 唯一真源（笔记文件） |
|------|----------------------|
| 桌面端 | `%APPDATA%\RFNOTER\data\notes_<你的ID>.json` |
| 网页端 | 项目目录下的 `data/notes_<你的ID>.json` |

两种形态都会在浏览器 localStorage 里保留一份离线副本，真源读不到时仍然可以继续记录。

状态提示的含义：

- 顶部 **读取本地文件失败 · 正在使用本机副本** / **读取服务器失败…**：真源暂时读不到，现在用的是本机副本。
- 顶部 **有改动未写入本地文件**（网页端显示为"服务器"）：本地有改动还没落到真源，点右下角那条提示即可重试。
- 右下角绿色「已保存」：已经写进真源了。

> 如果第一次打开时提示"检测到本机保存着 N 条笔记，但本地文件上还没有这份数据"，说明本机有历史数据而真源是空的（常见于从旧版本升级）。点「确定」会把本机笔记导入真源；点「取消」会先自动备份本机副本，再以真源为准。**程序不会在没问你的情况下覆盖任何一边。**

## 常见问题

- **AI 总结报 400 / 模型不存在**：内置模型名可能已经过期，在高级设置里重新输入密钥，让下拉框自动刷新出可用模型。
- **AI 总结报 401**：密钥无效或已过期，重新申请一个。
- **AI 总结报 429**：请求过于频繁，稍等一会儿再试。
- **笔记没有保存**：桌面端检查磁盘空间、确认数据目录可写；网页端确认 `npm start` 的服务还在运行。然后点右下角那条提示重试。
- **桌面端关掉窗口后程序还在？**：这是有意的——关窗口只是收进托盘，否则全局热键会失效。真正退出请用托盘菜单里的「退出闪录」。
